# undmg.github.io

My portfolio — an editorial, print-style page with a cover portrait
printed in colour ASCII.

- `index.html` — the page
- `css/style.css` — styles
- `js/main.js` — torn paper edge, ASCII portrait renderer, scroll reveals
- `js/portrait-data.js` — the portrait as ASCII characters + colours (no photo is published)
- `img/` — project screenshots

No build step: it's plain HTML, CSS and JavaScript served by GitHub Pages.
